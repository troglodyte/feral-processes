# Breeding — plan

Spec: `docs/superpowers/specs/2026-10-06-breeding-design.md`. Branch
`breeding`, worktree `../feral-processes-breeding`. Read the spec once. This
plan adds only what the spec left open: decisions, sites, task split, gates.

**Execution:** four tasks, serial, one sonnet subagent each. Each task uses the
previous task's types. Per-task review gates are off. One opus whole-branch
review runs at the end.

Every task uses TDD (failing test first, commit at each green step), then
`cargo fmt` and `cargo clippy --workspace --all-targets`, then the task's
tests. `cargo test --workspace` runs at the end of T1, T3 and T4.

Every dispatch prompt says: **never push**; never `git checkout`/`stash`;
stage explicit paths only (never `art/`); unset `FERAL_DEV_NO_SIEGES`; work
only in the `breeding` worktree.

Engine paths are under `crates/engine/src/`. Line numbers are at `825d1688`.

## Decisions taken here

- **Constants** (`tuning.rs`, beside `MIN/MAX_INDIVIDUAL_ROLL` at :999):
  `BREEDING_MUTATION = 0.04`, `BREEDING_GEN_STEP = 0.03`,
  `BREEDING_ROLL_HARD_CAP = 1.4`, `BREEDING_ATTRIBUTE_HARD_CAP = 3`, and
  `BREEDING_COOLDOWN_TICKS` and `INCUBATION_TICKS`, both
  `= SORTIE_BOARD_ROTATION_TICKS` (a reference, not a copy).
- **Components:** `Generation(u32)` and `BreedReadyAt(u64)`. An absent
  component reads as 0 or "ready". `Incubator { slots: Vec<Option<Incubation>> }`
  is inserted wherever construction completion inserts other per-structure
  components. Find that place by following where a Quarantine Rack gets
  `Racked`.
- **Attribute mutation** is uniform over `{-1, 0, +1}`.
- **RNG:** `breed` draws from the game's seeded RNG and nothing else does.
  The new components and resources can still reorder queries. If a seed-luck
  test moves, read
  `memory/new-resource-shifts-query-iteration-order.md` before touching it.
- **Read API for the UI**, because app-core can't see the World. These go in
  `views.rs` style:
  - `Game::breed_refusal(a) -> Option<BreedRefusal>` dims cooldown rows.
  - `Game::breed_preview(a, b) -> BreedPreview` returns the species (or the
    pair), the generation, and a per-roll `(min, max)`. It calls the same
    clamp helper that `inherit` uses. Don't copy the bounds.
  - `Game::incubations(bay) -> Vec<IncubationView>`.
- **Seed drop table:** `glitch 0.08, drone 0.08, scrapper 0.06, worm 0.06`,
  all non-boss OpenGrid commons. Price comes from the drop-only consumable
  band in `assets/items/README.md`.
- **Bay cost:** the same material tier as `quarantine_rack.ron`, with
  `incubation_slots: 1`.
- **Hybrids (approved by the user):**
  - `botnet` = worm × virus, glyph `b`, stats ≈ the mean of its parents.
  - `polymorph` = glitch × trojan, glyph `p`, stats ≈ the mean of its
    parents.

  Check that each glyph is unused. Each hybrid's stat shape must pass
  `stat_shape_faults` (species.rs:804).
- **Vague time words:** reuse whatever helper sortie and research sheets use
  today (grep for it). Don't add a new one.

## T2 — Engine breeding (rules, breed, incubation, hatch)

- New module `breeding.rs` holds:
  - `child_species`
  - `inherit` and its clamp helper
  - `ParentRolls`, `ChildRolls`, `Incubation`, `BreedRefusal` (with a
    `reason()` row fragment)
- `Game::breed` goes in `game/breeding.rs`. Check every refusal before the
  first mutation, following the `fuse_companions` pattern (party.rs:1424).
- Read API: see Decisions.
- Hatch:
  - A per-tick check over `Incubator`s.
  - A new acquisition door built on `roster_parts` (spawning.rs:466), plus
    `install_innate_routines` (combat.rs:1158) and `seat_derived`
    (derived.rs:301).
  - Stats = species base × rolled potential, with no zone, depth or rarity
    multiplier.
  - Hold the child while `roster_room()` (catalog.rs:887) is 0. Log one
    line when it hatches.
- Demolition is refused while a slot is occupied. Add this in the existing
  demolish refusal path under `game/base/teardown.rs`.
- Tests:
  - the spec's engine list
  - each refusal leaves seeds, cooldowns and the bay unchanged
  - parents stay usable mid-incubation (fight, fuse)
  - `inherit` never copies trained stat points past the clamp
  - mutation-check `inherit`'s caps

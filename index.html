Feral Processes

Tame the rogue programs you fight. Compile them into a base that runs itself. Then descend the Stack.

A Neuromancer/Tron-flavoured simulation of the Grid, blending Pokémon, Palworld and Dwarf Fortress. Built in Rust, with a headless sim that stays fully decoupled from what draws it.

Get it → Read the manual

What you actually do

Fight it, compile it, put it to work

Everything you beat is a candidate for your roster, and everything on your roster is labour you are not spending yourself.

01 — COMBAT

Tame and fight

Party-versus-party round battles with grouped enemies, where only the front groups can reach you. Decompile a hostile to add it to your roster; five can fight beside you at once.

02 — ROUTINES

Routines, not spells

Abilities install into level-derived slots and come from species kits, research, wild carriers, or a Compiler's extraction. Some cast straight from the map as run-long buffs.

03 — PRODUCTION

Cronjobs and chains

Post programs to structures and they work tick by tick wherever you are. Machines feed each other by touching, so a production line is a physical line laid across your base.

04 — PROGRESSION

Research and gear

A 23-node tech tree unlocks structures, benches and recipes. Equipment spans three slots, most of it made from what your own lines produce — and gear and programs both fuse, up to three times.

05 — AUTONOMY

A base that runs without you

Needs decay, cronjobs pay out, and GC Entropy Sweeps chip at your buildings while you are four frames underground. File a work order and the base schedules its own labour.

06 — STAKES

Permadeath, or Forgiving

Chosen per run. Achievements are the one thing that outlives a run, and they pay out at the start of the next one.

Underground

The place notices what you take from it

Scattered across every zone are links down into the Stack — procedurally generated frames drawn in first person, where the fights are harder and the returns are better.

  • Doors, sealed vaults and caches — and breakpoints, faults and corrupted ground between them.
  • Orphaned programs waiting to be adopted, their species pinned to the frame and their stats to the moment you took them.
  • A seeded guardian in the deepest room. Beat it and the stack comes down, taking the way back out with it.
  • A Trace meter that rises with everything you take. It is what hunts you.

Deeper zones double every wild stat, and the only way into one is a portal you fund yourself — with fragments the Stack is the sole source of.

Install

Clone it and run it

You need the Rust toolchain. A debug build is a playable build here — cargo run is how the game is meant to be started.

The binary resolves assets/, saves/ and your profile relative to the checkout at build time, so the clone needs to stay put — even if you cargo install --path crates/launcher to get it on your PATH.

View on GitHub → Release notes
bash
# if you don't have Cargo yet
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# then
$ git clone https://github.com/troglodyte/feral-processes
$ cd feral-processes
$ cargo run -p feral-processes

Moddable by design

Content is a file, not a code change

Species, structures, items, routines, achievements, contracts, talents and research nodes are all plain .ron data. A malformed file is skipped with a warning, never a crash — and a new field is always optional, so nobody's mod stops parsing.

assets/species/my_program.ron
(
    id: "my_program",
    name: "Null Pointer",
    habitats: [StaticField, OpenGrid],
    growth_multiplier: 1.4,
    moves: ["pointer_stab"],
    abilities: [(id: "segfault", level: 6)],
)

Difficulty tuning is deliberately not data. Every knob the engine hardcodes — scaling curves, XP, drop rates, raid pressure — is a documented constant in crates/engine/src/tuning.rs. Content is moddable; how hard the game is, is not.
